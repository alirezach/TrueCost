# Privacy Policy

**True Cost** respects your privacy.

## Data Storage

All settings (hourly wage, language, currency, custom site selectors) are stored locally in your browser via `chrome.storage.sync`. No data is sent to any external server by the extension.

## Network Requests

The extension makes **one** outbound network request: fetching the wage dataset from GitHub (`raw.githubusercontent.com/alirezach/TrueCost/master/data/wage-dataset.json`). This is used solely to suggest a default minimum wage on first install. If the request fails, a bundled local copy is used instead.

## No Tracking

- No analytics or tracking scripts
- No cookies
- No personal data collection
- No third-party services

## Open Source

This extension is fully open source. You can audit the code at any time at [github.com/alirezach/TrueCost](https://github.com/alirezach/TrueCost).
